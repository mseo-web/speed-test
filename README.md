# Утилита замера скорости скачивания (Speed Test CLI)

Консольная утилита на Node.js для точного измерения скорости сетевого скачивания по заданному URL. Скрипт написан на чистом JavaScript (ES Modules) и использует **исключительно встроенные возможности Node.js** без сторонних npm-зависимостей.

---

## Требования к окружению

- **Node.js**: версия `18.0.0` или выше (рекомендуется `24.0.0+` / `26.0.0+`).
- Поддержка нативного `fetch`, `node:perf_hooks`, `node:readline/promises`, `AbortSignal.timeout()`.

---

## Быстрый старт

### 1. Запуск с указанием целевого URL

Передайте URL первым аргументом командной строки:

```bash
node index.js https://example.com/large-file.zip
```

или через npm:

```bash
npm start -- https://example.com/large-file.zip
```

### 2. Интерактивный запуск (со значением по умолчанию)

Если аргумент командной строки не передан, утилита предложит ввести URL в консоли:

```bash
node index.js
# или
npm start
```

Вы увидите приглашение:
```text
Целевой URL не передан в аргументах командной строки.
URL по умолчанию: https://speed.cloudflare.com/__down?bytes=10000000

Введите URL для теста (или нажмите Enter для значения по умолчанию):
> 
```

- Нажмите **Enter**, чтобы использовать дефолтный тестовый файл размером 10 МБ от глобальной сети Cloudflare Anycast CDN.
- Или введите свой URL и нажмите **Enter**.

## Как это работает

1. **10 последовательных запросов**: Скрипт выполняет ровно 10 итераций скачивания по указанному URL.
2. **Точный учет размера**: Размер скачанных данных определяется по фактической длине полученного буфера в памяти (`response.arrayBuffer().byteLength`), а не по заголовкам `Content-Length`, которые могут отсутствовать или быть искажены сжатием.
3. **Высокоточный таймер**: Время замеряется с помощью `performance.now()` из модуля `node:perf_hooks` — от момента отправки запроса до полного завершения чтения тела ответа в память.
4. **Предотвращение кэширования**:
   - К каждому запросу добавляется уникальный параметр строки запроса `_speedtest_cb=<timestamp>_<attempt>`.
   - В запрос передаются HTTP-заголовки `Cache-Control: no-cache, no-store, must-revalidate` и `Pragma: no-cache`.
5. **Безопасность и таймауты**: Каждый запрос защищен таймаутом в 15 секунд через `AbortSignal.timeout(15000)`. При ошибке сети, HTTP-ошибке (статус отличный от 200–299) или таймауте скрипт завершает работу с кодом выхода `1`.

## Единицы измерения и формулы расчета

Для соответствия общепринятым стандартам индустрии используются следующие правила перевода единиц:

### 1. Стандарты единиц

| Величина | Единица | Стандарт | Коэффициент перевода |
| :--- | :--- | :--- | :--- |
| **Объем данных** | Мегабайты (МБ / MB) | Двоичный (MiB) | $1 \text{ МБ} = 1024 \times 1024 \text{ байт} = 1\,048\,576 \text{ байт}$ |
| **Скорость в МБ/с** | Мегабайты в секунду (МБ/с / MB/s) | Двоичный | $1 \text{ МБ/с} = 1\,048\,576 \text{ байт/с}$ |
| **Скорость в Мбит/с** | Мегабиты в секунду (Мбит/с / Mbps) | Десятичный (SI, стандарт провайдеров) | $1 \text{ Мбит} = 1\,000\,000 \text{ бит}$ ($1 \text{ байт} = 8 \text{ бит}$) |

> [!NOTE]
> В телекоммуникациях и сетевых спецификациях скорость традиционно указывается в десятичных мегабитах в секунду ($10^6$ бит/с), в то время как размер файлов в операционных системах отображается в двоичных мегабайтах ($2^{20}$ байт). Утилита рассчитывает и отображает оба значения.

### 2. Формулы

- **Общий объем (МБ):**
  $$\text{Total MB} = \frac{\sum_{i=1}^{10} \text{Bytes}_i}{1\,048\,576}$$

- **Чистое суммарное время скачивания (секунды):**
  $$\text{Total Duration (sec)} = \frac{\sum_{i=1}^{10} \text{Duration (ms)}_i}{1000}$$

- **Среднее время одного запроса (мс):**
  $$\text{Avg Request Time (ms)} = \frac{\sum_{i=1}^{10} \text{Duration (ms)}_i}{10}$$

- **Итоговая средняя скорость (МБ/с):**
  $$\text{Speed (MB/s)} = \frac{\text{Total MB}}{\text{Total Duration (sec)}}$$

- **Итоговая средняя скорость (Мбит/с):**
  $$\text{Speed (Mbps)} = \frac{\left(\sum_{i=1}^{10} \text{Bytes}_i \times 8\right) / 1\,000\,000}{\text{Total Duration (sec)}}$$
